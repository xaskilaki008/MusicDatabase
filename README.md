# MusicDatabase

Personal music database project.

## Description
A personal music catalog designed for managing tracks, artists, albums, genres, playlists and their relationships.

## Technologies
- PostgreSQL
- Docker
- Docker Compose
- SQL
- Git
- GitHub

## Project structure
- `database/migrations` — database structure changes
- `database/views` — predefined database views
- `database/functions` — reusable SQL functions
- `database/queries` — query library
- `database/seeds` — initial data
- `backups` — local backup storage

## Deployment
The project will be deployed using Docker Compose.
